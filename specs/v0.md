# v0

## decisions (v0)

- rooms live in memory only. restart loses games, fine for now
- room registry = map + one mutex. join does lookup + full check + fill under ONE lock (check-then-act race)
- tokens are random from crypto/rand, not JWT. token on connect/reconnect = which player you are
- one goroutine per room runs the match top to bottom. it only starts once both players are in
- one reader goroutine per connection, one writer goroutine per player. nothing else writes to a socket
- outbound channel is buffered. full = treat player as disconnected (slow client can't stall the room)
- server does all timing with time.Now
- round winner: fewest guesses, then fastest. both fail = draw. tied match = draw in v0
- room removes itself from the registry when the match ends
- restructure before the WebSocket server
